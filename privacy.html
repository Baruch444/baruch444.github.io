Privacy policy

Last updated: 10 November 2026

NS Media Operations ("the app") is a private tool operated by a single creator to publish videos to the creator's own YouTube channels.

What the app accesses

With the creator's consent through Google sign-in, the app requests two YouTube scopes: youtube.readonly, to confirm which of the creator's channels it is connected to, and youtube.upload, to upload videos the creator has approved.

What the app stores

The app stores the OAuth refresh token for each connected channel on the creator's own computer, plus the channel ID, channel title and the IDs of videos it uploaded. It does not collect, store or share data about any other person, viewer or YouTube user.

Sharing

No data is sold, shared with third parties or used for advertising. Google user data is used only to provide the upload function described above.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it stops all uploads at once, because the stored token stops working.

Contact

Questions about this policy: open an issue in this site's GitHub repository.
